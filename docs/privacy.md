# Privacy

Kopra stores clipboard entries, saved file copies, preferences and local search ranking in your user profile. It records app identity for recent-app suggestions, not window titles or document contents from the foreground app.

Copying a file into history creates an independent copy. The app may read a cloud placeholder to save that copy, which can cause your existing cloud provider to download the original.

Optional pairing sends new clipboard copies to the one device you confirm. Existing archives are not bulk transferred. Excluded apps and supported confidential-clipboard markers apply before sharing. Camera access is used only while the QR scanner is open; Kopra does not save camera frames.

The default retention is 30 days for text and seven days for images and files. Pinned entries remain until you remove them. The default storage budget is 2 GB, with 5 GB of free disk space reserved. Settings explain what each limit changes.

You can pause capture, unpair a device, clear unpinned history or clear all history. Deletions and pins do not propagate to the other computer. Removing the app does not automatically delete your history folder.

Kopra has no account, telemetry service or cloud backend. Build tools download their own declared dependencies during development. Release installers do not download a separate runtime.
